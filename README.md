# Hydrogeological Water Balance and AI-Based Drought Forecasting Framework

This repository contains the datasets, Python notebooks, and results associated with the article:

**“On Forecasting Hydrological Drought and Water Balance in central Italy: Assessing Irrigation Deficit and Water Reuse Opportunities in the Sentina area”**

Authors: Nicolò Ciuccoli*, Davide Fronzi, Alberto Tazioli, Anna Laura Eusebi, Francesco Fatone  
Affiliation: Università Politecnica delle Marche (UNIVPM), SIMAU Department  
*Corresponding author: Nicolò Ciuccoli (n.ciuccoli@staff.univpm.it)

## Overview

The framework integrates a hydrogeological water balance, one-month-ahead drought and water availability forecasting, and the assessment of treated wastewater reuse opportunities in the Sentina coastal basin, central Italy.

The analysis combines hydro-climatic data from the ISPRA BIGBANG model with basin-scale water balance calculations, environmental flow requirements, and water demand. Forecasting focuses on the three-month Standardized Precipitation Index (SPI3), the three-month Standardized Precipitation Evapotranspiration Index (SPEI3), and net available discharge (`Q_disp`). The water balance analysis identifies irrigation deficits and evaluates the contribution of treated wastewater reuse.

## Running the Notebooks

1. Download or clone the repository, preserving its folder structure.
2. Install Python, JupyterLab or Jupyter Notebook, and the packages required by the notebook you intend to run.
3. Open the relevant notebook in `Code/` and check its input and output paths.
4. Run the notebook cells in order. The balance and forecasting notebooks export their results to `Results_Balance/` and `Results_Forecasting/`, respectively.

For paths that work on both Windows and Linux, use `pathlib`. For example, when the working directory is `Code/`:

```python
from pathlib import Path
import pandas as pd

dataset_dir = Path("..") / "Dataset"
Data = pd.read_excel(dataset_dir / "Q_tot.xlsx")
```

Relative paths are resolved from the current working directory. You can check it with `Path.cwd()` and adjust the paths if you launch Jupyter from a different directory.

## Dependencies

Depending on the notebook, the workflow uses the following packages:

| Component | Packages |
| --- | --- |
| Notebook environment | `jupyterlab` or `notebook` |
| Data processing and Excel input | `pandas`, `numpy`, `openpyxl` |

Check the import cells in each notebook for its specific requirements. Python standard-library modules such as `pathlib`, `os`, and `datetime` do not require separate installation.

## Reproducibility Notes

- Preserve the exact folder and file names when running the notebooks, particularly on Linux.
- Input datasets are stored in `Dataset/`; the two analysis notebooks in `Code/` generate the outputs stored in `Results_Balance/` and `Results_Forecasting/`, respectively.
- Package versions, model settings, random seeds, and input data can affect forecasting results. Retain these settings when reproducing an analysis.
- The framework can be adapted to other study areas by replacing the input datasets and updating the basin-specific parameters.
